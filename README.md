# Website-demo

Welcome to the repository for my personal portfolio website. 

## Overview
This project is a static, responsive portfolio designed to showcase my academic background in Software Engineering and my professional focus on Technical Consulting and Business Analysis. 

## Sections Included
* **About Me:** A brief introduction bridging my technical foundation with my strategic goals, along with a few personal interests.
* **Career Focus:** Highlighting my primary domains: Technical Consulting, Data Analysis, and Business Analysis.
* **Contact:** My professional contact information and a functional message form.

## Technologies Used
* HTML5 & CSS3
* Bootstrap 5
* JavaScript (for UI interactivity)

## Deployment
This website is deployed and hosted directly via GitHub Pages.
